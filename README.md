# PillReminder
Jednostavna Aplikacija MojaTerapija, da nikada ne zaboravite na svoje lijekove. 
Funkcije:
* Neograničen broj lijekova,
* Više opcija ponavljanja,
* Više opcija odgode, 
* Pračenje zaliha lijeka sa podsjetnikom,
* Pračenje dnevnog pridržavanja uzimanja,
* Historija uzimanja,
* Skočni prozor za podsjetnike, 
* Automatsko utišavanje tokom poziva,
* Režim odmora, 

Lokalizacija: EN, BS, HR, SR
---------------------------------------------------------------
Simple MojaTerapija Application, so that you never forget your medicines.
Features:
* Unlimited number of medicines,
* More replay options,
* Multiple snooze options,
* Tracking drug supplies with a reminder,
* Monitoring of daily intake compliance,
* History of intake,
* Pop-up window for reminders,
* Automatic mute during calls,
* Rest mode,

Localization: EN, BS, HR, SR
